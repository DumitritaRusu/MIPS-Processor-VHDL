 Washing Machine Controller (VHDL)

This is a project I worked on with a classmate for our Digital Systems Design course. We used VHDL to build the control logic for a washing machine, with manual settings and a few preset washing programs.
The goal was to practice designing a digital system from smaller components and connecting a control unit with a datapath.

Features

- Manual mode with options for temperature, spin speed, prewash and extra rinse.
- Five automatic washing programs: Quick Wash, Shirts, Dark Clothes, Dirty Clothes and Anti-Allergy.
- Calculation of the washing time based on the selected settings.
- Counters for tracking the remaining time and the one-minute delay after the washing cycle.
- LED indicators for the machine status and door lock.
- A 7-segment display for showing the timer.
- A VHDL testbench for simulating the system.

 Technologies Used

- VHDL
- Xilinx Vivado
- Finite State Machines (FSM)
- Digital logic design


This project helped me better understand how digital systems are designed using VHDL.
I also got more familiar with finite state machines, counters, ROM modules and organizing a larger design into smaller components.
Working on it as a team was a good opportunity to practice combining different modules into one system.
